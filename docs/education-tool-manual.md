# 学历与学位证书核验助手 — 操作说明书

## 1. 工具用途

学历与学位证书核验助手是一款独立运行的 Windows 桌面工具，用于批量处理候选人毕业证书和学位证书：

1. 导入毕业证书或学位证书图片或 PDF；
2. 使用用户配置的大模型识别姓名、证书编号、学校和专业；
3. 为每位候选人打开独立的学信网页面，填写查询信息并尝试识别图片验证码；
4. HR 使用手机扫码并人工确认最终查询结果；
5. 检测到最终结果页后，批量保存统一规格的网页内容截图。

工具与 BOSS 简历筛选器共用现行学历与学位核验实现，但模型配置、API Key 和截图目录偏好相互独立。

### 学历和学位分别查询

同一队列可以混合导入毕业证书和学位证书。识别后，文件名前显示 `[学历]` 或 `[学位]`，右侧“证书类型”可人工更正。类型无法识别时显示“待确认”，确认类型后才能查询；请核对姓名与对应证书编号，不要混用两类证书编号。

- 学历证书使用[学历查询入口](https://www.chsi.com.cn/xlcx/lscx/query.do)。
- 学位证书使用[学位查询入口](https://www.chsi.com.cn/xwcx/lscx/query.do)。
- 每张证书在同一 Chrome 窗口内使用独立标签页；按网页提示完成验证码和可能出现的手机确认，再确认最终结果。
- 学位结果截图文件名含“学位核验”，学历结果含“学历核验”，同名候选人的两类结果分别保存。修改类型后需要重新查询；处理中不能更改类型。
- 学位零散查询范围为 2008 年 9 月 1 日以来的相关学位证书信息，详见[学信网查询范围](https://www.chsi.com.cn/help/cxfw.jsp)。查不到记录不等同于证书无效。

## 2. 运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（64 位） |
| 浏览器 | Google Chrome |
| 网络 | 能访问所配置的大模型接口和学信网 |
| 本地权限 | 当前用户可使用 Windows 凭据管理器并写入 `%LOCALAPPDATA%` |

### 2.1 安装与启动

普通用户下载 [EducationCertificateTool.exe](https://github.com/yaoyouzhong/boss-resume-filter/releases/latest/download/EducationCertificateTool.exe) 后双击启动，无需安装 Python 或 Anaconda。GitHub 下载较慢时，可从 [Gitee Release](https://gitee.com/yaoyouzhong/boss-resume-filter/releases) 下载同名文件。

源码开发或调试时，也可以在项目依赖安装完成后运行：

```bash
python education_tool.py
```

独立工具不会读取 BOSS 主程序的模型配置或 API Key。

## 3. 首次配置模型

首次运行会直接进入“模型配置”页。以后可从证书核验页右上角点击“模型配置”进入。

### 3.1 配置步骤

1. 选择服务商；自建接口或中转服务选择“自定义”。
2. 输入模型名称、API Key 和 Base URL。
3. 可点击“自动识别并获取模型”读取当前接入渠道的模型列表。
4. 点击“保存模型”。
5. 在“当前识别模型”中选择实际使用的模型。
6. 点击信号灯或“测试连接”，查看连接结果和图片识别测试结果。
7. 点击“返回证书核验”。

图片证书需要支持图片输入的视觉模型；带文本层的 PDF 先提取文字，因此可以使用文本模型。工具会按模型名称提示可能不支持图片输入的配置，但不会阻止 PDF 文本识别。

保存、切换模型时，工具会自动检测图片识别能力；手动测试会重新发送程序生成的数字图片，识别正确才显示“已验证支持图片识别”。连接成功不代表图片测试通过，测试未通过时只表示多模态能力尚需验证。成功验证的结果在重启后继续生效，测试不会使用你的证书图片。

### 3.2 配置和 Key 保存位置

- 模型名称、服务商、Base URL 等非敏感信息：
  `%LOCALAPPDATA%\EducationCertificateTool\config.json`
- 截图目录等界面偏好：
  `%LOCALAPPDATA%\EducationCertificateTool\preferences.json`
- API Key：Windows 凭据管理器，服务名为 `education-certificate-tool`

API Key 按服务商和 Base URL 分开保存，不写入 JSON、证书文件、日志或 EXE。换电脑后需要重新输入 API Key。

## 4. 导入和识别证书

### 4.1 支持格式

| 类型 | 格式 |
|---|---|
| 图片 | JPG、JPEG、PNG、BMP、WEBP |
| 文档 | PDF（支持文字版和扫描版） |

PDF 可在预览区翻页查看。扫描版 PDF 支持每份 1 至 6 页，多份证书请分别导入。

点击“导入证书”可一次选择多个文件。重复路径会自动跳过，导入不会修改或复制原始证书。

### 4.2 批量识别

点击“识别证书”会处理当前队列，最多并行识别三份证书，并逐条更新进度和状态。也可在队列中选择记录后通过右键菜单单独识别。

图片识别包含：

- EXIF 方向校正；
- 四个方向对比；
- 姓名和证书编号重点区域复核；
- 低置信度和字段冲突提示。

识别后应人工核对姓名和证书编号。字段有误时可直接修改。图片方向不正确时点击“顺转 90°”；双击预览可查看按当前方向显示的完整原图。

程序不会仅因证书编号不足 18 位要求人工复核；字段缺失、低置信度或识别结果冲突仍需核对。多条提示分行显示，并随窗口宽度换行。

## 5. 学信网验证

### 5.1 打开查询页

1. 确认证书类型正确，姓名和证书编号完整；
2. 选择一条或多条记录；
3. 点击“打开学信网验证”。

工具只启动一个独立 Chrome 窗口，并在该窗口内为每位候选人创建单独标签页，填写姓名和证书编号，然后尝试识别并提交验证码。各标签页按顺序启动，避免把不同候选人的状态相互覆盖；如果某个标签页创建失败，工具会保留当前窗口并提示重新执行，不会继续启动新的 Chrome 窗口。

### 5.2 验证码处理

验证码支持字符和简单算术题。工具会生成多种清晰化图片进行识别，低置信度结果不会自动提交。

自动识别失败时：

- 可以点击“重新识别验证码”；
- 也可以直接在 Chrome 中手工输入验证码并提交；
- 连续失败后状态会转为“待人工验证”，不会伪报成功。

### 5.3 手机扫码和最终结果

验证码通过后，HR 必须使用手机扫码并完成确认。工具会继续检查页面状态，并区分：

- 等待手机扫码；
- 二维码已过期；
- 查询页字段已清空；
- 未查询到学历记录；
- 已出现最终核验结果；
- 页面已关闭或浏览器连接中断。

“验证码已提交”或“出现二维码”都不等于核验成功。只有明确检测到最终结果页，记录才会进入可截图状态。

## 6. 批量保存结果截图

手机确认完成并出现最终结果后，点击“保存核验结果”。

- 每次批量截图都需选择本次保存目录；上次目录仅作为选择窗口的初始位置，取消则不截图；
- 只截取网页内容，不包含浏览器工具栏和桌面；
- 自动裁掉大面积空白并统一输出规格；
- 文件名统一为 `姓名_学历核验_年月日_时分秒.png` 或 `姓名_学位核验_年月日_时分秒.png`，如 `张三_学位核验_20260910_153025.png`；不再显示证书尾号和校验串。
- 再次点击“一键批量截图”会重新截图并替换本轮对应原文件，照片仍在加载或截图失败时保留原文件；重新核验后生成新的截图时间，同名冲突自动追加序号，原文件保留。
- “截图与保存”区域可点击“打开文件夹”查看当前保存目录。
- 截图前检查结果照片是否出现并加载完成；最多等待约 5 秒，仍未就绪则提示稍后重试，不保存本次截图。再次点击“一键批量截图”可重新获取照片完整的页面，并更新本轮截图；
- 查询无记录的项目明确标记为无需截图；
- 页面显示逐项截图状态及本次保存、跳过、待补和失败数量。

如果 Chrome 被关闭，可重新打开学信网验证；工具不会把表单页、验证码页或二维码页保存成最终结果。

## 7. 常见状态

| 状态 | 含义 |
|---|---|
| 待识别 | 已导入，等待大模型识别 |
| 识别中 | 正在提取证书字段 |
| 已识别 | 字段已提取，可人工核对 |
| 打开中 | 正在创建并填写学信网页面 |
| 识别验证码中 | 正在读取当前标签页验证码 |
| 待人工验证 | 自动识别未达到提交条件，需要人工处理 |
| 等待手机扫码 | 验证码已通过，等待 HR 手机确认 |
| 二维码已过期 | 需要在页面刷新二维码后继续 |
| 未查询到记录 | 学信网明确返回无匹配记录，应核对输入字段 |
| 结果已生成 | 已检测到最终核验结果，可截图 |
| 打开失败 | 页面已关闭、连接中断或页面结构不匹配 |

截图列会另外显示待截图、已保存、已存在、无需截图、文件异常或截图失败等状态。

## 8. 常见问题

### 提示未找到 API Key

进入“模型配置”，重新填写当前服务商和 Base URL 对应的 API Key 并保存。只复制 `config.json` 到另一台电脑不会带走凭据。

### 图片识别失败

检查图片清晰度、方向和当前模型是否支持图片输入。识别失败不代表证书无效。

### PDF 识别失败

扫描版 PDF 自动将整页转换为图片（保留文字、印章和分层图像），再由视觉模型识别，无需手动转换。每份 PDF 支持 1 至 6 页；多份证书请分别导入。

### 无法打开 Chrome

确认 Chrome 已安装且能正常运行。学历核验使用自动分配的调试端口，不依赖 BOSS 登录浏览器或固定 9222 端口。

### 学信网页面已经改变

如果页面结构与当前适配规则不一致，自动填写、验证码或结果检测可能停止。此时保留原页面并人工完成查询，不要把“打开失败”理解为学历异常。

## 9. 隐私和安全边界

- 证书图片和提取出的文字会发送给用户选择的大模型服务；
- 原始证书只从用户选择的位置读取，不会自动复制到工具数据目录；
- 队列和识别结果只保存在当前运行内存中，关闭工具后不会恢复；
- 只有用户执行截图时，最终结果图片才会写入选定目录；
- API Key 由当前 Windows 用户的系统凭据保护，不包含在可执行文件中。

识别结果只是查询辅助，最终结论以 HR 在学信网页面看到并核对的结果为准。

PDF 可直接在证书预览区查看；多页文件支持上一页、下一页，支持顺转 90° 和双击放大当前页。预览不调用 AI。

“保存到”仅在本次截图成功后显示实际保存目录；启动、导入新证书或开始新一轮截图时不显示上次路径。

截图统计按本轮显示“已保存／未保存／保存失败”。历史文件不计入本轮已保存，选择目录不会改变保存数量；重新执行批量截图时重置本轮统计。

“打开文件夹”在本轮至少成功保存一张截图后启用，打开本轮实际保存目录；启动、导入新证书和开始新一轮截图时禁用。
