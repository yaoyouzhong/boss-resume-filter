# 页面设计优化验收说明

本次采用 emil-design-eng 的操作反馈、视觉一致性和高频交互原则，保留 Tk 桌面架构与原有业务流程。

## 已实施

| 页面或组件 | 变化 |
| --- | --- |
| 全局 | 主色、背景、文字与边框色统一；页面标题沿用首页字号层级，减少标题容器占用；副标题随宽度换行 |
| 首页 | 正常的运行准备状态降低视觉权重，警告和错误继续保留语义色 |
| 筛选结果 | 统计卡恢复原有图标尺寸，图标与数字文字整体居中，四卡等宽；整块点击、悬停和焦点反馈；支持 Enter / Space 打开明细；保留小窗口收起图标与全部表格字段 |
| 岗位配置 | 保存操作使用主按钮，保存状态在底部操作旁同步显示 |
| 运行控制 | 开始、停止、状态、进度和浏览器条件提示独立固定在页面标题下方，进入页面和查看日志时都可见；未运行时收起进度区，运行时显示细进度条，结束后只保留结果说明；摘要提供筛选结果入口 |
| 证书核验 | 当前可执行步骤突出显示；旋转支持键盘操作；长预览提示自动换行 |
| 数据统计 | 汇总卡采用等宽、整体居中的图文组合，增加反馈样本口径及岗位复盘入口说明 |
| 系统设置 | 标题右侧“快速定位”菜单提供模型、备份及诊断分区入口；保存模型为主按钮 |
| 反馈 | 默认错误及警告持续显示到关闭或被新消息替换，显式指定时长仍生效；替换消息取消旧计时器；关闭按钮可用键盘；结果表连续查看提示时跳过重复延迟 |

未改变筛选分数、联系资格、证书核验条件、存储格式及模型调用方式。高频操作保持即时响应，没有引入额外动效依赖。

## 本地复验

- `pack_venv\Scripts\python.exe tests/run_unit_tests.py`：稳定回归。
- `pack_venv\Scripts\python.exe tests/test_import.py`：导入烟测。
- `pack_venv\Scripts\python.exe tests/manual/preview_design_polish.py --verify`：七页真实 Tk 控件、紧凑布局、键盘统计卡、等宽卡片居中、日志旁运行操作、证书步骤强调、提示计时器验证。
- 去掉 `--verify` 可保留演示窗口进行人工操作。仅使用临时目录中的模拟岗位、候选人、模型配置和证书图片；停用浏览器连接、模型凭据读取和启动更新。该脚本只用于界面验收，不用于验证真实扫描、发送或学信网查询。

本机 Windows 真实窗口已检查结果页整卡点击、运行页首屏及滚动时均可见的独立操作区、设置页分区定位。macOS 和不同系统 DPI 组合仍需要对应设备验收，不将本机截图作为跨平台完成证据。
