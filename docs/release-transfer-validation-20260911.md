## 实现与验证范围

- GitHub 每段 1 MiB，最多 4 路；片段独立重试，保留校验记录，重启后复用有效片段。
- 每次读取最多等待 15 秒，片段总时限 60 秒，在收到数据时检查；使用非填满缓冲的读取方式识别慢速持续传输。
- 每段校验 Content-Range 和长度，整包 size/SHA-256 校验通过才发布到本地成品路径。
- 不支持 Range 时回退普通续传，其他分段失败保留进度并报告错误。
- 上传保持流水线，状态区分 queued/uploading/complete/failed；下载和上传线程对状态文件的读改写串行化。
- 本地 HTTP 实测已覆盖连接中断、片段重试、进程重启检查点复用、缓存损坏、整包校验失败、Range 不支持与持续低速限时退出。
